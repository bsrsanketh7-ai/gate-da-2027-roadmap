# GATE DA 2027 Roadmap

A 19-week study plan for GATE DA (Data Science & Artificial Intelligence) 2027. It runs from 26 September 2026 to the February 2027 exams and covers the full official syllabus.

- Tick topics off week by week. Progress is saved in your browser (localStorage).
- Includes key dates, the paper pattern, score targets, approximate marks per subject and free resources.

It is a single static `index.html` with no build step. You can deploy it on Vercel or GitHub Pages as-is.
